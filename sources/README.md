# Vendored Python sources

These files are verbatim copies of the Python that the visualizations display.
They live here so a clean checkout can build and deploy without the parent workspace.
Do not edit them here, because the app presents them as the books' original code.

- `python-master/` contains code from _Grokking Algorithms_ by Aditya Bhargava, copyright Manning Publications.
- `grokking_data_structures-main/` contains code from _Grokking Data Structures_, distributed under the Apache License 2.0 in its `LICENSE` file.
